Code and pipelines

Software

Open-source tools and analysis pipelines for transit radio telescopes, calibration, foreground mitigation, and 21 cm cosmology.

My research is built around reproducible, end-to-end analysis. I contribute to collaboration software and maintain tools developed for my own observing programs.

Python · radiocosmology

draco

Pipeline building blocks for the analysis and simulation of data from transit radio interferometers. I contribute analysis components used in CHIME and related 21 cm workflows.

Python · CHIME

ch_pipeline

The CHIME analysis pipeline, including data-processing infrastructure for calibration, beamforming, foreground filtering, and validation.

Python · telescope modelling

driftscan

Models transfer functions for drift-scan telescopes and generates products used to filter foregrounds and estimate 21 cm power spectra.

Python · sky simulation

cora

Simulates low-frequency radio skies, including polarized Galactic synchrotron emission, point sources, and cosmological 21 cm signals.

CASA · uGMRT

GMRT DI Calibration Pipeline

My public direction-independent calibration and RFI-flagging pipeline for uGMRT Band 3, Band 4, and Band 5 data.

Validation · CHIME

Daily validation

Notebooks and diagnostics used to monitor analysis products and test the stability of CHIME data-processing outputs.
